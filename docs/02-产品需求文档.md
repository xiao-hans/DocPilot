## 1. 产品愿景

DocPilot 是一个面向多个客户的通用文档处理平台。客户无需为每种文档开发专用程序，即可配置文档类型和字段，处理文档、复核结果、归档搜索，并逐步把结果接入业务流程。

## 2. 用户与需求

| 用户 | 目标 | 主要痛点 |
|---|---|---|
| 平台运营人员 | 管理客户、配额、服务状态和支持 | 缺少租户生命周期、用量和运维视图 |
| 租户管理员 | 配置团队、角色、模板和数据策略 | 配置与用户管理依赖技术人员 |
| 操作成员 | 上传/导入文档并查看处理结果 | 手工录入、重复处理、状态不透明 |
| 复核人员 | 对照原文纠正低置信度结果 | 无出处定位、版本和审阅记录 |
| 集成开发者 | 通过 API 获取状态与结构化结果 | 当前没有稳定 API 身份、版本及事件约定 |

## 3. 核心用户旅程

1. 用户注册/接受邀请，进入所属租户空间。
2. 租户管理员创建文档类型和字段模板。
3. 成员上传一批文件；平台校验、存储并创建任务。
4. 系统识别/解析/抽取，记录来源、状态、置信度和警告。
5. 复核人员在原文与结果间核对、修正并确认。
6. 已确认文档进入客户文档库，支持筛选、全文/字段搜索、导出。
7. 管理员配置触发器和动作，逐步自动通知、审批或调用集成。

## 4. 产品原则

- 租户间隔离是平台基础约束，不依赖前端过滤。
- 模型输出应带状态/来源并允许人工校正；不将不确定的推断伪装成确定值。
- 原始文件、处理结果、模板版本和审阅变更可关联追溯。
- 提取、搜索和自动化作为不同能力模块，由稳定数据模型连接。
- 首期先做可验证的人工上传闭环，导入方式逐步扩展。

## 5. 版本路线（初步）

### V1：多租户基础与文档提取闭环

租户/成员/权限、持久化任务、上传与安全校验、模板管理、PDF/常用图片解析、提取结果复核、文档/任务历史、基础筛选导出、平台审计基础。

### V1.5：文档管理与搜索

文档分类、标签、元数据筛选、OCR 文本搜索、重复检测、保留/删除策略、批量操作。

### V2：流程自动化与集成

可配置规则、审批/通知、API key、Webhook、幂等回调、API/网盘/邮箱接入及集成运行状态。

### V3：平台化运营

套餐/配额/计量、客户自助开通、服务等级、扩展格式/语言、分析仪表盘和可选高级部署能力。

## 6. 成功指标（目标值待基线化）

- 用户可在无开发介入下创建模板并完成首次文档处理。
- 上传成功的任务都可查询状态；服务重启后任务和结果仍存在。
- 任一租户无法读取、修改或推断另一租户的文件、结果、模板和任务。
- 提取字段可追溯到文档及模板版本；人工修订有审计记录。
- 失败任务可诊断并按策略重试，不产生重复副作用。
- 搜索、自动化和集成能力在后续版本可基于同一租户/文档/事件模型扩展。

## 7. 非目标和待确认

首期不承诺完全自动化业务决策、行业合规认证或特定云厂商。需产品评审确认首批客户画像、计费方式、数据地区、保留/删除周期、SLA、首期文件格式上限、语言、搜索范围以及自动化是否纳入首期。
