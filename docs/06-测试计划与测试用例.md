## 1. 测试目标

验证多租户隔离、文档处理正确性、任务恢复、结果可追溯、审阅流程、搜索和导出安全。测试优先覆盖跨租户越权、敏感文件处理、重复任务、部分失败和持久化恢复等高风险场景。

## 2. 测试范围

### 范围内

需求/设计静态评审、单元、API 集成、数据库迁移、队列/Worker、端到端浏览器、权限与租户隔离、安全、负载/容量、备份恢复、可用性/可访问性。

### 范围外（待具体版本）

未选定的云厂商认证、正式渗透测试认证、未接入的集成商验收和未知监管框架合规认证。

## 3. 测试策略

| 层级 | 重点 | 自动化目标 |
|---|---|---|
| 静态评审 | 需求可验证性、设计威胁面、迁移/回滚、文档追踪 | PR checklist / lint |
| 单元 | 权限策略、状态机、字段校验、幂等、文件名处理、导出转义 | CI 每次提交 |
| 集成 | API+DB、对象存储、队列、Worker、外部服务替身 | CI/预发布 |
| 系统/端到端 | 登录、模板、上传、处理、复核、检索、导出 | 每个发布候选 |
| 安全 | 跨租户对象引用、角色滥用、注入、文件炸弹、CSRF/SSRF、密钥与日志 | 自动化回归+定期人工评估 |
| 性能/恢复 | 上传吞吐、队列积压、搜索分页、Worker 扩展、备份恢复 | 预发布按基线目标执行 |
| 可用性 | 键盘导航、错误反馈、长任务状态、屏幕阅读器语义 | 关键流程抽查 |

## 4. 环境与测试数据

- CI 环境：临时数据库、队列、对象存储模拟器和 OCR/LLM stub；无真实客户数据和生产密钥。
- 预发布：与生产拓扑接近，使用合成/脱敏文档，启用安全日志和可观测性。
- 测试租户至少 A/B 两个、不同角色用户及平台管理员；使用重复 ID/路径参数进行越权验证。
- OCR/LLM 通过录制夹具或 stub 保证稳定；另设受控质量评估集跟踪提取准确率，避免把模型非确定性用例混入普通单测。

## 6. 进入与退出条件
### 进入

需求和设计已评审；构建版本固定；迁移脚本可在空库及上一版本数据库运行；测试环境与依赖可用；测试数据无真实隐私数据。

### 退出/发布候选

- 所有 P0 用例通过；P1 结果经产品/测试负责人接受。
- 无未处理的严重/高危安全缺陷；例外有责任人、期限和补偿措施。
- 关键端到端流程和跨租户隔离自动化覆盖已运行。
- 备份恢复、回滚、告警和任务积压处理已有执行记录。
- 结果与失败用例、缺陷、代码版本关联并留档。

## 7. 缺陷分级与报告

P0：跨租户泄露、数据丢失、关键服务不可用；P1：核心流程阻断或绕过权限；P2：重要功能缺陷但有替代路径；P3：轻微体验/显示问题。缺陷报告记录环境、版本、租户/角色（用测试 ID）、前置条件、复现步骤、期望/实际、日志关联 request_id、严重度和回归用例。

## 8. 测试限制

本文件定义计划与用例，其中身份、租户隔离、任务闭环及文档元数据事务部分已自动化并执行通过（见 §5.1）；容量门槛、准确率基线、浏览器矩阵、PostgreSQL 备份恢复目标和完整安全测试范围仍需在需求/架构评审时确认。
