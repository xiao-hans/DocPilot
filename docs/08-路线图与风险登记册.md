## 1. 交付路线建议

| 阶段 | 目标结果 | 关键依赖/出口条件 |
|---|---|---|
| A. 产品与架构基线 | 确定客户/部署、数据边界、首期范围、质量目标、身份和存储选型 | 产品负责人批准 G0；技术负责人批准 G1 |
| B. 多租户基础 | 身份、租户/成员/角色、持久化数据库和审计 | 越权测试通过；迁移/备份策略通过评审。**当前状态**：角色矩阵、邀请与只追加审计已实现并自动化通过负向越权用例；备份恢复策略与 PostgreSQL 迁移重放尚未评审，出口条件未全部满足 |
| C. 文档处理闭环 | 文档存储、模板版本、队列/Worker、解析提取、状态/错误 | 重启恢复、幂等、部分成功和基本安全用例通过。**当前状态**：模板版本、幂等键、尝试记录、超时收敛与 `partial` 已实现并自动化通过；单进程执行、无租约续期、PostgreSQL 未验证 |
| D. 复核与文档库 | 原文预览、人工修订、历史、筛选、导出 | 结果版本/审计可追溯；角色授权通过。**当前状态**：文本预览、只追加修订链、数据库层乐观并发、确认/退回状态机、文档库筛选与治理角色拆分、XLSX/CSV 同源导出已实现并自动化通过（226 项全绿、`alembic check` 无漂移、前端构建通过）；界面与字段值检索未交付 |
| E. 搜索与自动化 | 全文/字段搜索、事件规则、通知/审批 | 索引隔离、规则版本、重试/幂等明确 |
| F. 运营与集成 | 计量、套餐、API/Webhook、导入连接器、SLO | 容量测试、配额、告警、回滚/恢复运行就绪 |

上述为逻辑顺序，不是已批准的排期或交付承诺。

## 3. 风险登记

| ID | 风险 | 概率/影响 | 缓解与触发信号 |
|---|---|---|---|
| R-001 | 多租户隔离遗漏导致客户数据泄露 | 中/极高 | 集中租户上下文、DB 约束/RLS、跨租户负向测试；任何越权缺陷触发阻断发布 |
| R-002 | 文件恶意内容或解析资源耗尽 | 中/高 | 签名检测、隔离处理、CPU/内存/页数限制、扫描策略；异常峰值/Worker 崩溃触发告警 |
| R-003 | 外部 OCR/LLM 使用导致隐私或数据驻留不符 | 中/高 | 供应商审查、用户告知/配置、脱敏策略、禁止训练承诺确认；未审查前禁用生产敏感数据 |
| R-004 | 内存任务模式无法支持重启/并发 | 高/高 | 首期替换持久化任务与队列；服务重启导致任务丢失视为发布阻断 |
| R-005 | OCR/LLM 质量不稳定导致错误数据进入业务流程 | 高/高 | 字段置信度、原文定位、人工复核、评估集和错误更正追踪 |
| R-006 | 任务重复投递或失败重试产生重复导出/审批 | 中/高 | 幂等键、唯一约束、outbox/事件状态、重复投递测试 |
| R-007 | 文件删除未覆盖派生文本、索引或备份 | 中/高 | 定义生命周期清单、异步删除状态、定期清理核对及备份保留规则 |
| R-008 | 范围包含提取、搜索、自动化、集成导致首期过大 | 高/中 | 分阶段路线；V1 限定手动上传核心闭环和基础检索 |
| R-009 | Vue 构建与后端托管/反向代理发布配置不一致 | 低/中 | 后端现优先托管已构建的 `frontend/dist`；仍需将构建步骤纳入部署并完成发布流程验证 |
| R-010 | 缺少容量与SLA目标使选型/成本不可控 | 高/高 | G0 明确预期租户数、文件量、峰值并发、延时和恢复目标 |
| R-011 | 邀请令牌无投递渠道，管理员需人工转交，可能被转到错误的人或经第三方通道泄露 | 中/中 | 令牌短期有效且仅一次使用；接入官方投递渠道前，客户文档需说明人工转交责任；异常接受记录进审计事件 |
| R-012 | 成员与邀请管理只有后端能力，无前端界面，运营只能直接调 API | 高/低 | 阶段 B 收尾后优先排入界面；在界面就绪前不得宣称客户可自助管理成员。**扩展**：阶段 C/D 的模板管理、复核工作台、文档库与导出同样只有 API，界面统一排在交付前补 |
| R-013 | `processing_jobs.snapshot` 与 `extraction_results` 双真相，读路径未完全切换 | 中/中 | 阶段 D 已让两者同事务写入；`/results`、`/export` 以规范化值为源，`/result`、`/excel` 仍读快照。读路径全部切换并通过追踪后再退役快照列 |

## 4. 待确认决策

1. 目标市场/地域与数据驻留要求、适用隐私法规和合同义务。
2. 首期登录体验：邮箱密码、邀请制、SSO；是否提供租户自助注册。
3. 首期格式、文件大小/页数、语言、批次和容量目标。
4. 身份、数据库、队列、对象存储、密钥和监控的部署/供应商约束。
5. 文档保留、软删除、彻底删除、备份清理和客户导出政策。
6. 计费/配额是否需要首期实现；租户套餐边界。
7. 文档检索是精确字段/全文检索，还是还需要语义搜索/问答。
8. 工作流首期是否只做通知，或必须含审批与外部动作。
9. 处理结果需不需要页码/坐标级来源定位和置信度门槛。
10. 目标 SLA、RPO/RTO、并发、响应时间和可接受模型成本。
