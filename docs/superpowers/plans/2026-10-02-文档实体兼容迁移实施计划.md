# 文档实体兼容迁移实施计划

> **执行方式：** 在当前会话内逐项实施，不启动子代理。每项按测试先行、实现、验证、提交推进。

**目标：** 新上传文件同时写入租户隔离的 `Document`/`DocumentVersion` 元数据和现有任务快照，保持旧任务与 API 兼容。

**架构：** 每个上传文件创建一个 `Document` 与一个不可变 `DocumentVersion`；文件版本通过 `job_id` 关联产生它的任务。元数据与任务快照在同一数据库事务中提交，文件写入失败或事务失败时清理本次文件和未持久化的内存任务。历史任务继续只从现有 JSON 快照读取。

**技术栈：** FastAPI、SQLAlchemy、Alembic、SQLite/PostgreSQL、pytest、临时文件系统。

## Task 1：固定模型约束与迁移

**Files:** 上表中的 `app/models/document.py`、`app/models/__init__.py`、`migrations/env.py`、新迁移文件、`tests/conftest.py`、`tests/test_document_assets.py`。

- [x] **Step 1：先写模型约束测试**

新增测试，使用 `owner_workspace` 建立有效租户/任务/文档数据，并直接在 `SessionLocal` 中尝试以租户 A 的版本关联租户 B 的文档或任务。测试断言 SQLAlchemy `IntegrityError`，回滚 session 后查询无残留记录。

`````python
from datetime import datetime, timezone
from uuid import uuid4

import pytest
from sqlalchemy.exc import IntegrityError

from app.db import SessionLocal
from app.models.document import Document, DocumentVersion
from app.models.job import Job
from app.services.job_repository import JobRepository


def test_document_version_rejects_cross_tenant_document(owner_workspace, other_workspace):
    now = datetime.now(timezone.utc)
    owner_job = Job(
        id=uuid4().hex, fields=[], created_at=now.timestamp(),
        tenant_id=owner_workspace["tenant_id"], owner_id=owner_workspace["user_id"],
    )
    other_job = Job(
        id=uuid4().hex, fields=[], created_at=now.timestamp(),
        tenant_id=other_workspace["tenant_id"], owner_id=other_workspace["user_id"],
    )
    JobRepository().save(owner_job, owner_job.tenant_id, owner_job.owner_id)
    JobRepository().save(other_job, other_job.tenant_id, other_job.owner_id)
    document_id = uuid4().hex
    with SessionLocal() as db:
        db.add(Document(
            id=document_id, tenant_id=other_workspace["tenant_id"],
            owner_id=other_workspace["user_id"], status="active", created_at=now,
        ))
        db.commit()

    with SessionLocal() as db:
        db.add(DocumentVersion(
            id=uuid4().hex, document_id=document_id,
            tenant_id=owner_workspace["tenant_id"], job_id=owner_job.id,
            revision=1, original_filename="invoice.pdf",
            storage_key=f"{owner_job.tenant_id}/{owner_job.id}/random.pdf",
            checksum="a" * 64, media_type="application/pdf", size_bytes=12,
            created_at=now,
        ))
        with pytest.raises(IntegrityError):
            db.flush()
        db.rollback()

    with SessionLocal() as db:
        assert db.query(DocumentVersion).count() == 0
```

- [x] **Step 5：接入上传及元数据计算**
