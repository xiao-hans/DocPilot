# DocPilot 项目文档

> 项目方向：通用型、多租户文档处理平台。阶段 B–F 已交付；阶段 G 设计已评审，G0 容器环境、G1（本机 Compose + PostgreSQL 迁移门禁 + 备份恢复演练）与 G2（RabbitMQ + 自建派发器/Worker + 执行租约与超时回收，见 `docs/adr/0004`）已于 2026-10-03 交付，G3–G6 待实施。当前容量规划目标为 100 个租户、约 1TB 文件、最多 100 个并发处理任务；只做本地 Docker Compose 开发验证，暂不部署线上服务器。服务等级、合规边界、容量验收阈值与生产技术供应商仍待确认。

## 文档状态约定

- **草案**：待产品负责人和技术负责人评审，不作为已承诺的交付基线。
- **已批准**：范围和验收标准已确认，可据此进行设计、实现和测试。
- **已废弃**：被后续版本或决策替代；保留以供追溯。

需求编号采用 `BR`（业务）、`FR`（功能）、`NFR`（质量属性）、`SEC`（安全）和 `OPS`（运维）。需求变更应同步更新 SRS、设计、测试用例和追踪矩阵。
